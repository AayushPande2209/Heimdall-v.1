# Hardware

The current prototype uses a FLIR Lepton 3.5 and Raspberry Pi 4. Wiring details
for VSYNC, Lepton enable, the status LED, and the recording/shutdown button are
recorded in `rig/recorder/README.md`.

No CAD, STL, complete BOM, or assembly drawing was present in this checkout at
the time of restructuring. Add editable source CAD under `hardware/cad/` along
with finalized STLs and `hardware/bom.csv` when they are ready.

The planned design-file license is CERN-OHL-W, subject to checking the final
license text against the released design. Assembly documentation and instructions
are planned for CC BY 4.0. No hardware license is applied today because no
publishable hardware design is present.
